  附：driver/token.py 的**文件名遮蔽**问题（Task 10/11 都踩到，已修）
═══════════════════════════════════════════════════════════════════════
  症状：以脚本方式跑 driver/ 下任何文件时，标准库链
        dataclasses -> inspect -> linecache -> tokenize -> `from token import *`
        命中了我们的 driver/token.py（计划 Task 10 指定的文件名），
        报 `ImportError: cannot import name 'dataclass' from partially
        initialized module 'dataclasses'`（看着像循环导入，实际是文件名遮蔽）。
  修法：先把自己所在目录从 sys.path 摘掉、**再** import 标准库 token、钉进
        sys.modules。守卫放在 dnfdrive.py（driver/ 下的共同导入点）与 token.py。
  **顺序是关键** —— 三组对照实测（2026-10-05）：
        不装守卫                          -> FAIL（复现遮蔽）
        摘路径**之前**就 import token      -> FAIL（守卫自己也被遮蔽）
        先摘路径、再 import               -> OK（token.__file__ = …\Lib\token.py）
  回归：本报告 [A]–[D] 四段全部跑通，证明修好之后 driver/ 下所有入口都正常。
