副本与组队

本文适用于第一章 ACT1；内容以当前实现为准，第二章的组队与副本表现可能不同，以游戏内实际显示为准。

进入副本​

  1. 在城镇与地下城入口或相关 NPC 交互，选择要进入的副本。
  2. 满足等级、任务或门票等进入条件后才能进入；不满足时入口不会开启。
  3. 单人可直接进入；组队时由队长选择副本，队员会跟随进入同一个副本实例。
  4. 在副本内逐房间清怪、换房，击败 BOSS 后进入通关结算。
  5. 通关后可翻牌并返回城镇。

组队​

  1. 邀请：左键点击同屏玩家，在玩家菜单中选择“邀请组队”；对方接受后成队。邀请窗口有时间限制，超时后需要重新邀请。
  2. 创建/加入：也可以通过“队伍信息”创建队伍，或从“推荐伙伴/申请加入”加入已有队伍。
  3. 人数：队伍名册最多 4 人。队长可以解散队伍或移除成员；队长离开时，队长身份会自动移交给其他成员。
  4. 不自动退队：进入副本、回城、换城镇或城镇内换区都不会退队；换频道会离开当前队伍。
  5. 金币分配：普通金币会在本房间合格成员之间均分，余数给拾取者；死亡后换房会失去本房间的分配资格。
  6. 掉落确认：部分高品质掉落会弹出确认窗口，可选择拾取、掷点或放弃；普通物品按掷点分配。

通关与翻牌​

  • 通关结算后会显示翻牌。翻牌分为免费牌和付费牌，付费牌会消耗金币，具体以结算提示为准。
  • 组队时每名成员看到属于自己的免费翻牌奖励；黑钻状态会在结算时同步。
  • 翻牌结束后返回城镇。奖励以实际入账为准，背包空格不足时可能无法领取。

返回城镇​

  • 通关结算后选择返回城镇是最稳妥的方式。
  • 在副本内使用 ESC → 返回城镇 会让自己退出队伍并回城，不会把队友一起带回；组队时请优先使用通关结算的返回。
  • 队员掉线或退出后，队伍会保留其余成员；队长掉线时自动移交。

人数与限制​

  • 队伍最多 4 人。
  • 更多人数、跨机器和长时间联机仍在完善中，可能出现怪物或队友位置短暂不同步。
  • 遇到卡门、卡怪或无法换房，先退出副本重新进入；仍无法恢复时按 启动问题 排查。

常见错误​

  • 不要在邀请超时后才点接受：窗口关闭后需要重新邀请。
  • 不要在副本内换频道或换角色：会中断队伍和当前副本进度。
  • 不要以为“返回城镇”会带走队友：副本内 ESC 返回只回自己，队友会留在副本。
  • 不要满背包或超重进副本：掉落和翻牌奖励可能无法领取，先清理背包。
