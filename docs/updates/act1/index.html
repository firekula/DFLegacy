第一章更新记录

本页是第一章 ACT1 的玩家向更新摘要。历史记录只适用于其记录的构建与场景，不代表当前安装全部通过验收；可下载内容以官方发布页为准。

2026 年 11 月历史更新​

2026-11-10 的更新（v0.1.11）​

  • 恢复天帷巨兽选图界面的天帷禁地入口。需要已经接取或完成任务 452「我在大陆的肚子里」，前置任务为 451「疑问的信息」，副本最低等级 34。已有该任务的角色更新后重新登录即可检查入口，不需要放弃并重接任务。
  • 更新窗口的阶段提示统一为中文，与标题左对齐并保持单行；较长的文件名以省略号显示，鼠标悬停可以查看完整文字。
  • 本次客户端更新包含新的游戏数据文件。客户端与服务器需要一致的数据：如果服务器尚未同步，入口或内容可能仍与说明不一致，需要等服务器更新后再试。

2026-11-10 的更新（v0.1.10）​

  • 修复冰心少年第二房间的文字绘制崩溃，以及通关清场时误杀冰之心的问题。修复版已在实际客户端的两种随机房间验证；通关后确认冰之心被保留、角色存活且翻牌正常。
  • 普通启动不再先显示验证窗口或等待网络：校验记录有效时直接打开登录界面，更新检查在后台进行，发现新版本后交给独立更新程序安装。显式修复和进入游戏的完整校验仍保留。
  • 对实际游戏数据的 43 个副本做了配置与房间生成排查，未发现新的同类错误。这不等于每张地图的所有技能和组队情况都已实测。

2026-11-09 的更新（v0.1.8）​

  • 赛丽亚商店保留原有 98 个位置，新增 201 种有正原价的材料；63 种缺少价格的材料暂不出售。
  • 新增有界的基本故障报告，可在设置中关闭。原始转储只保留在本机，不会自动上传。
  • 固定启动入口可以在登录界面被删除或损坏后自动修复；更新程序损坏时使用经验证的恢复副本。

v0.1.8 与 v0.1.10 之间有一个未公开发布的候选版本。玩家不需要为它做任何操作，直接按发布页提供的最新包更新即可。

这些旧版本如何升级​

退出第一章游戏，从原来的第一章启动图标打开。保持架构（x86 或 x64）和普通版／测试版一致。v0.1.6 及更早的客户端可能先收到兼容更新包，请按提示完成并重启。

离线修复时，第一章启动／修复包需要解压到有兼容原版游戏资源的目录，保留自己的账号和显示配置。若更新后的商店或任务与记录不同，先向所在服务器确认游戏数据版本。安装与选包 · 更新问题 · 已知问题
