网络与连接问题

本文适用于第一章 ACT1 与第二章 Chapter Two。服务器地址、选区和频道由启动器与登录流程管理，先按顺序排查。

连接超时或登录失败​

  1. 确认启动器里选择的**服务器（选区）**是你要玩的那一个。选错区会一直连不上或看不到角色。
  2. 用浏览器确认能打开官方发布页；连发布页都打不开时，问题在本地网络。
  3. 暂时关闭 VPN、代理和第三方网络加速工具再试。它们会改变连接路径，可能导致登录或进图失败。
  4. 换一个网络（例如手机热点）对比结果。只有一个网络失败时，优先检查该网络的防火墙或运营商限制，而不是重装游戏。
  5. 第一次进游戏会校验安装清单，网络差时表现为长时间等待；先看 更新问题 区分是下载还是连接。

选区与频道​

  • **选区（服务器）**在启动器的登录界面选择，决定你连接哪台服务器；频道在登录后选择，是服务器内部的玩家分组。
  • 角色数据保存在服务器上。换一个选区（服务器）登录时看不到原来选区的角色，这是正常的；回到原选区即可看到。
  • 同一城镇、同一区域、同一频道的玩家才能互相看见。城镇内换区域不影响队伍，换频道会离开当前队伍。
  • 频道人数和状态以游戏内列表为准，拥挤时换一个频道再进入。

组队掉线或卡顿​

  • 掉线、换频道、切角色都会中断当前副本进度，组队时优先完成手上的副本再切换。
  • 组队中个别成员网络很差时，其他成员也可能感到短暂变慢。目前不会为了“保新鲜”而丢弃已排队的可靠数据，也不会因为某个人慢就强制踢人。
  • 出现掉线时，请队伍双方都保留 Logs/DFLegacy/ 目录，并记录：故障的当地时间和时区、双方角色名、队长是谁、副本与房间、当时正在战斗/换房/翻牌，以及客户端是卡住、弹窗退出还是直接消失。
  • 服务端只能看到经过它的数据，无法据此计算玩家之间的网络质量；因此双方日志比单方面描述更有用。

本机中继与防火墙​

  • 第一章的原版客户端是 IPv4 程序。服务器只提供 IPv6 地址时，启动器会启动本机中继做转接；中继只在本机监听，不会把你的电脑变成公网服务器。
  • 如果系统防火墙或安全软件拦截本次启动的启动器或游戏进程，表现通常是登录超时、进图失败或组队时掉线。请在防火墙提示中允许本次程序，而不是关闭全部防护。
  • 第一章的中继端口来自启动器保存的配置（launcher.json 中的中继端口列表）；需要调整时按服务器提供的配置更新，不要手写或在外部猜一组合适的端口。
  • 第二章的中继地址与端口由启动器按本次登录自动分配，不要手工修改或猜映射。
  • 中继端口被旧实例占用时，先关闭遗留的启动器或游戏窗口再重试；第一章的配置中继和第二章的自动分配中继都可能遇到。
  • 同一台电脑不要同时运行两个客户端写同一个目录；需要同时开多个客户端时，使用互相独立的安装目录。
  • 中继只在本次游戏会话内有效，退出游戏后自动释放；不要把它的地址分享给别人。

IPv4 与 IPv6 边界​

  • 第一章客户端通过本机中继连接 IPv6 服务器，这不等于游戏本身原生支持 IPv6；IPv6 支持是由中继转接实现的。
  • 第二章由启动器解析服务器地址，每次进入游戏重新解析。连接过程中服务器地址变化不保证无缝恢复，需要重新登录，并等待地址解析生效。
  • 切换网络（有线、无线、热点、IPv6 与 IPv4 之间）后，请退出并重新登录，不要在原地等待连接自动恢复。

常见错误​

  • 不要在副本内换频道或切角色：会中断队伍与副本进度。
  • 不要用“改 hosts”“换 DNS”来修连接问题：可能让地址解析更乱，排障时也说不清哪一步生效。
  • 不要把 0.0.0.0 或 :: 当作服务器地址填写：这是监听地址，不是玩家可用的连接地址。
  • 不要相信“网络优化工具”“加速器”类第三方程序：可能要求注入游戏进程或提供账号信息。
