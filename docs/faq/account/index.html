账号问题

本文适用于第一章 ACT1 与第二章 Chapter Two。两章的注册与登录入口相互独立，账号规则也不完全相同。

注册失败​

  1. 先看提示文字。提示账号已存在时不要重复提交，直接改用登录或找回密码。
  2. 账号格式不合法时按 账号与角色 的规则修改：第一章账号 4–32 位，密码 6–128 个字符，QQ 码至少 5 位。
  3. 第二章的输入范围更窄：账号 4–16 位字母数字，新注册或重置的密码 6–16 位字母数字。超出范围会直接失败。
  4. 提示连接失败时，先回到 网络与连接问题 确认服务器可达，再重试一次。
  5. 公开注册只会创建普通账号。测试账号无法通过公开注册获得，仅存在于测试环境。

密码规则​

  • 第一章密码为 6–128 个字符，支持较长密码；第二章新密码为 6–16 位字母数字。
  • 第二章登录允许 1–16 位密码，这是为了兼容迁移过来的旧短密码；新建或重置时仍按 6–16 位执行。
  • 忘记密码时使用启动器内的找回密码流程，需要注册时填写的 QQ 码。不要反复试错。
  • 改密需要先登录取得权限。没有登录时无法直接改密。

登录受限​

  • 连续输错密码可能触发临时限制，稍后再试或改用找回密码。具体等待时间以界面提示为准，本页不承诺固定时长。
  • 提示“账号或密码错误”是统一提示，不会区分账号不存在还是密码错误，这是出于账号安全考虑。
  • 不要多人共用同一账号：角色、点券和账号状态会互相影响，也无法判断是谁的操作。
  • 第二章使用独立启动器，两章账号不自动互通；在第一章注册的账号不一定能登录第二章，以该启动器的提示为准。

角色不显示​

  1. 确认登录的是原来的选区（服务器）。角色按服务器保存，换一个选区后看不到原选区的角色。
  2. 确认账号没有输错，尤其是多账号使用时。
  3. 确认章节正确。第一章与第二章是两套安装和数据，角色不跨章共用。
  4. 确认已选择频道并进入角色列表；只登录到启动器不会加载角色。
  5. 以上都正确仍看不到角色时，先只描述现象，账号信息按维护者要求提供，并附上发生时间与截图。

反馈前准备什么​

  • 角色名、所在区与频道；账号信息按维护者要求再单独提供（任何时候都不要提供密码）。
  • 发生时间与你的时区，以及当时看到的完整提示文字。
  • 启动器登录界面显示的版本号、系统版本和是普通版还是测试版。
  • 复现步骤：点了哪些按钮、当时在登录还是已经进入城镇。
  • 截图，以及 Logs/DFLegacy/ 目录。日志可能包含账号相关上下文，公开上传前先审查。

不要这样做​

  • 不要把账号密码发给任何人：工作人员不会索要密码、验证码或远程控制权限。
  • 不要因为登录失败就反复狂点：可能触发临时限制。
  • 不要买卖、租借或共享账号：无法追回损失，也不受支持。
  • 不要用他人提供的“内部账号”“测试账号”登录：来源不明的账号可能被随时收回或用于诈骗。
