更新问题

打开登录页后没有更新提示​

第一章已通过校验的安装可能先打开登录页，再在后台检查更新。第二章 v1.0.18 群包升级到 v1.0.19 时会经过两步，过渡版本会先显示更新窗口。若收到「离线验证」提示，本地文件可用，待联网后才能确认是否已是最新版。第二章升级说明

下载中断或速度变慢​

  • 看进度栏当前处于下载、校验还是安装。校验主要读取本地文件，下载速度暂时为零也可能仍在工作。
  • 提示限流或网络错误时，按界面给出的时间稍后重试。保留已下载的文件，从同一快捷方式重开，启动器会复用通过校验的内容。
  • 提示空间不足时，看安装阶段需要的空间。仅够放下载分卷的空间，可能放不下替换文件和备份。

安装失败或反复修复​

  1. 正常退出游戏并关闭同目录的其他启动器，重新打开原入口。安装中断后，程序会先处理未完成的更新。
  2. 保留安装目录内的 .dflegacy；第二章新版的更新状态在 client/.dflegacy。删除或改写这里的文件会使程序失去原有恢复记录。
  3. 如果始终提示同一文件校验失败，记下文件名和完整提示。使用对应章别的修复功能或匹配的启动／修复包；需要改用完整整合包时，解压到独立目录。选择正确的包
  4. 仍然失败时，提供故障时间、章节和当前版本，保留相应的 update- 日志。支持与反馈
