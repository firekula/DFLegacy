# 启动时自动更新的小进度窗

依据用户本轮明确指定的行为直接实施；沿用现有 286×104 原版素材，无新增视觉方案。

- 登录窗口在启动检查完成前不显示。无更新或检查失败时进入登录；失败使用原版提示说明可重试。
- 发现更新后仅显示小进度窗，自动下载、校验、交接安装助手、重启登录器。常规更新不再要求手动切换页面或点击安装。
- 进度从左侧固定起点填充：下载占前 80%，之后由校验、交接、备份、替换、回读校验、重启完成推进。未知等待不循环滚动，也不靠计时伪造进度。
- 同版本且本地清单和文件有效时不重复下载。手动检查也走同一流程。
- 保留更新源、哈希、包类型、进程身份与命名管道校验、文件占用检测、备份和恢复事务。中断事务仍明确确认恢复；失败不得声称更新完成。
- 普通/测试包分别更新；保留配置、原版 IJL、EXE、PVF、NPK。实测使用独立目录。

采用现有控制器和事务增加薄的窗口协调层与实际阶段进度；放弃继续使用完整更新页，因为用户已明确要求小窗和自动流转。
