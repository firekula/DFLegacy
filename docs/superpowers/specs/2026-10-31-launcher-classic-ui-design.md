# 登录器原版素材界面定稿

用户已确认第二轮登录页、设置页预览“可以，完美”，并在此前确认原版服务器选择方案。本设计落实这些已批准图片，不再另选视觉方向。

## 定稿依据

- `artifacts/launcher-ui-audit-20261031/preview/revision-2/login.png` 与 `settings.png`，均为567×512组合预览；设置面板480×428，顶部额外23像素用于原版DNF装饰。
- 服务器选择采用上一轮原版地图背景与唯一“本地服务器”条目；登录页不显示任何服务器列表/条目。
- 提取报告与每项图片来源见同目录 REPORT.md、manifest.json、preview/asset-transforms.json。原始资产和用户客户端保持只读。

## 方法与接口

继续WPF与单文件发布。此前通用暗金侧栏方案被用户否定；采用原版位图边框和控件。新图仅为已有素材的确定性派生：干净边框、原尺寸装饰、单张不循环石纹及宣传画切片，随程序嵌入；构建不依赖本机F盘或提取工具。

文字采用系统宋体单色像素采样与1物理像素黑描边，亮金标签、暖白正文。实现者选择GDI光栅化和WPF绘制，保留Unicode、自动换行与无障碍文本；字体不是另行提取的游戏专用文件。缓存有界，GDI句柄必须成对释放。输入仍使用原生TextBox/PasswordBox；空值提示按实际字形垂直居中，不缓存密码图像。

顶部仅有注册、改密、找回、账号管理、游戏设置、更多服务。原网站/客服/充值/论坛链接移入更多服务。删除下方重复入口；已有本地账号选择保留在账号管理中。中部采用官方参考的左图右公告布局，使用内置欢迎/操作指南，不伪造实时新闻、日期和负载。

左侧“选择服务器”切换同一窗口的原版服务器页。仅显示一个本地服务器，实际端点来自已保存连接配置，不能把自定义域名/IPv6改写成127.0.0.1。确认只重新读取选择，不写配置；失效/改变的已保存配置清楚提示。该页面的Enter确认选择，Escape返回，不能启动隐藏的登录页。

设置页保持批准布局：两个顶部页签，主要分辨率/画质选择，折叠的路径与历史信息，固定保存区。默认显示游戏显示页。连接页全部旧字段可访问，独立保存；既有四目标核对、读租约、字节保持、错误/警告、重载与重启语义完整保留。更小工作区缩短可滚动内容区，保存与关闭始终可达。

所有图片按钮采用真正的Button，具备焦点、Space/Enter和正确名称；文本图像有真实文字AutomationPeer。弹窗遮罩、拖动、下拉项和禁用状态需实机检查。系统主题不能改变固定原版皮肤或造成白色下拉框。

## 验收与发布

新增有意义的实际GDI/WPF测试：单色文字/描边、实际字形居中、长路径换行、句柄及缓存边界、内嵌素材可读取。服务器选择使用真实临时配置文件验证端点和账号保留、零写入、外部变化及失败处理。界面颜色本身不写镜像测试，以实际窗口与批准图稿对照验收。

完整Launcher测试、原有托管/原生/Python/发行门禁维持。新界面单独接受一次全范围独立复核；此前原生缩放复核不重做。保留main原3个脏跟踪文件及163条状态记录，按已有授权快进、推送、CI发布、认证下载校验并安装测试目录；原426资源、原EXE、账号配置和无关INI字节保持。临时Runner在最终完成后恢复原暂停状态。
