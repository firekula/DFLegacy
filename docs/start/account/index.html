账号与角色

本文适用于第一章 ACT1 与第二章 Chapter Two；第二章启动器对账号名和密码的输入范围更窄，见下方“第二章注意”。

注册账号​

  1. 打开对应章节的启动器，点击“注册账号”。
  2. 填写账号、密码和 QQ 码。第一章的规则为：账号 4–32 位，密码 6–128 个字符，QQ 码至少 5 位。
  3. 公开注册只会创建普通账号；测试账号无法通过公开注册获得，仅存在于测试环境。
  4. 注册成功后返回登录界面，不要重复提交同一账号。

登录​

  1. 在启动器输入账号和密码登录。
  2. 忘记密码时使用启动器内的“找回密码/改密”流程，不要反复试错。
  3. 连续输错可能触发临时限制，稍后再试或改用找回流程。
  4. 在启动器登录页选择服务器（选区），登录后再选择频道并进入角色选择。

创建角色​

  1. 第一次进入且没有角色时，在角色选择界面创建角色。
  2. 每个手动新建角色初始获得 10 个复活币；已有角色不补发，重启或登录也不会自动补满。
  3. 角色数据保存在服务器；换一台机器登录同一账号，可以继续使用已有角色。
  4. 点券、黑钻和部分账号服务按账号共享，角色之间不重复计算。

第二章注意​

  • 第二章启动器当前要求：账号名 4–16 位字母数字，新注册或重置的密码为 6–16 位字母数字；登录允许 1–16 位密码，以兼容迁移来的旧短密码。
  • 如果你的账号或密码超出第二章界面的输入范围，请按界面提示另注册符合范围的账号或重置密码。
  • 第二章使用独立的启动器和账号入口，登录信息以该启动器的提示为准；不要假设两章的账号自动互通。

测试账号与普通账号​

  • 普通账号：通过公开注册获得，用于正常游玩。
  • 测试账号：仅用于测试环境；可能开放测试功能，但不代表正式服权益，也不会因此获得管理权限。

不要这样做​

  • 不要把账号密码发给任何人：工作人员不会索要密码、验证码或远程控制权限。
  • 不要多人共用同一账号：角色、点券和账号状态会互相影响。
  • 不要在第二章输入超长账号或密码：界面只接受上述范围，超长内容无法通过。
  • 不要因为登录失败就反复狂点：可能触发临时限制，先检查账号密码或使用找回流程。
