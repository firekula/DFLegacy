更新与修复

第二章群包升级请沿用原快捷方式。 v1.0.18 群包会先安装过渡版本，再安装 v1.0.19-r1。两个窗口可能先后关闭、重开。以最终登录页显示的 v1.0.19 和 游戏客户端 2.0.1.6 核对结果。查看本次更新

日常更新​

  1. 正常退出游戏，打开当前章节的启动器。第一章使用原来的第一章入口；第二章整合包使用根目录的 DFOLauncher.exe。
  2. 按提示下载和安装，留出暂存及替换文件所需空间。启动器会复用已匹配的文件。已经校验过的版本有时会先打开登录页，后台再检查更新。
  3. 中断后从同一入口重开，等待恢复或按界面提示重试。保留 .dflegacy，其中有本机安装记录、可复用的下载和恢复所需文件。
  4. 登录页提示离线验证通过时，本机文件已通过检查，线上版本仍需在更新源恢复后再确认。

什么时候用修复​

启动时提示文件缺失、摘要不匹配，或重复安装同一文件，可使用对应版本的校验／修复入口。入口本身已损坏时，按该章发行说明取得匹配的启动／修复包；新装完整包则解压到独立目录。更新期间请退出占用同一目录的游戏或第二个启动器。

很旧的第一章版本可能需要中间兼容包；第二章的旧入口也可能需要多次重启，按提示完成。账号、键位或画面设置有问题时，应先检查对应设置，文件修复不会重置个人偏好。下载与安装 · 更新问题
