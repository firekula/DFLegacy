# 第二章 v1.0.13-r2 小额过渡更新

本版是 v1.0.13 的小额过渡发行，用于把仍在 v1.0.12 的第二章客户端带到 v1.0.13，不需要重新下载完整游戏包。

- v1.0.12 客户端先安装约 170 MiB 的过渡组件（托管登录器、更新器、启动描述符和许可说明），固定启动入口保持 v1.0.12 原样，原快捷方式仍可启动旧版。
- 过渡登录器随后只下载约 0.4 MiB 的 v1.0.13 固定入口，在启动校验和回滚日志保护下完成一次入口切换；Script.pvf、ImagePacks 等游戏资源不重复下载。
- 下载中断、校验失败或新版启动校验失败时保留原入口和恢复副本，不会把安装留在半更新状态。
- 已安装 v1.0.13 的玩家只会按需更新托管登录器，v1.0.13 完整启动包和源码仍保留。
- 本版服务端与资源同 v1.0.13；没有部署线上服务，也没有切换玩家更新源。深渊房侧的已知问题见 v1.0.13 发行说明。
