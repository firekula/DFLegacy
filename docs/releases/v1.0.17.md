# DFLegacy 第二章 v1.0.17

> **2026-11-18 更新：本版本对应的 GitCode Release 已删除。** 当前发行链为 `v1.0.14` → `v1.0.14-bridge`（seq 24）→ `v1.0.15`（seq 25）；本文件只保留当时的构建与验收记录，不代表线上可更新版本。

## 本版内容

- 修复拆分布局的实际落地：启动器迁移只把启动器与 `.dflegacy` 放进 `client\`，游戏文件
  （`DNF.exe`、`Script.pvf`、`ImagePacks*` 等）留在安装根目录。
- 修复更新器入口的布局解析：`--bootstrap-client` 与独立修复入口现在也在读取受管理路径前
  解析分分布局，搬迁后不会再误判游戏文件缺失。
- 兼容旧版单启动器布局：`client\DNF.exe` 存在时，下次启动会把游戏文件抬回外层、启动器留在
  `client\`，并在失败时回滚；中断后可继续。
- 版本号 1.0.17。

## 升级路径

- `v1.0.14` / `v1.0.15` / `v1.0.16` 安装可直接更新到 `v1.0.17`：固定入口与受管理文件集合不变。
- 更新后首次启动若仍是旧版布局（游戏文件在 `client\` 里），新版 `DFOLauncher.exe` 会提示并整理到外层。
  该入口由启动包分发，不随 V4 更新替换。
