# DFLegacy 第二章 v1.0.19

## 本版内容

- 自动更新完成后，新登录器首次启动会把旧单启动器布局里的游戏文件移回安装根目录
  （`DNF.exe`、`Script.pvf`、`ImagePacks*` 等），启动器、`Logs` 与 `.dflegacy` 留在 `client\`；
  失败会回滚，可重复执行。
- 因此 `v1.0.14` 安装只需一次普通更新即可得到新布局；`v1.0.13-r2` 仍按既有链
  `v1.0.13-r2 → v1.0.14-bridge → v1.0.14 → v1.0.19` 自动推进（同一次启动内完成），最终由 v1.0.19 整理布局。
- 更新器、修复入口、更新助手都按请求里的安装目录解析布局；配置与依赖从安装根读取。
- 版本号 1.0.19。

## 签名说明

使用自签名调试证书（`CN=FireKula`）。Windows 会显示未知发布者/不受信任，不降低 SmartScreen 或杀软告警；
这不是受信任的代码签名。

## 升级路径

- `v1.0.14` / `v1.0.15` / `v1.0.16` / `v1.0.17` / `v1.0.18`：直接更新（固定入口 `8391eacc…` 不变），
  更新后首次启动自动整理为新布局。
- `v1.0.13-r2`：经既有桥接链自动更新到 v1.0.14，再更新到 v1.0.19；无需手工下载或替换入口。
