# 第二章 v1.0.13

## 客户端

- 原生启动组件的 stderr 警告会写入启动日志。`libpng warning: iCCP: known incorrect sRGB profile` 出现时，启动器继续等待实际握手及退出结果。
- 副本聊天支持拼音选词后发送，也支持在同一个输入框内切换中英文。单刷发送的副本聊天会回显到自己。
- 本地事故记录包含游戏进程退出码及启动阶段。配置联机诊断后，可在管理端「客户端故障」查看脱敏报告。

本版固定入口、托管登录器和更新器的文件版本均为 `1.0.13`。已有 v1.0.12 的玩家应下载所用镜像的完整启动包，解压到新目录后运行 `DFLegacy.Launcher.exe`。原入口的在线更新仍按已安装的文件校验。新目录可沿用自己的账号和游戏选项。

## 服务端

服务端为暗精灵墓地的队伍记录四个陵墓守卫击杀，并向同一副本的所有客户端下发 Boss 门状态。深渊房可提前离开，回访只恢复尚未击杀的陵墓守卫。已击杀的守卫不会重生，跳过的深渊敌人不会计入守卫击杀，也无需回来补打。

配套镜像为 `ghcr.io/firekula/dflegacy-chapter-two:v1.0.13`。管理员可另行安排更新，服务端继续从原持久卷读取存档和 PVF。

## 故障定位

使用 Windows PowerShell 5.1 复现了 v1.0.12 的启动报错。原启动脚本把原生组件写入 stderr 的 libpng 警告提升成终止错误，即使组件返回成功，也可能中断游戏会话。新脚本继续读取组件输出，按真实的启动握手和退出码判断。玩家首次进副本掉线需要该次客户端与服务端日志才能确定原因。
