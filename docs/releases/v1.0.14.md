# 第二章 v1.0.14 发行说明

日期：2026-11-17

## 本版内容

- **DFOLauncher 单启动器布局**：外层只有 `DFOLauncher.exe` 和 `client\`（完整客户端），其余 EXE、诊断、崩溃捕获和游戏资源收进 `client\`。
- **客户端升级到 1.0.14**：固定入口、托管登录器、更新器、诊断、崩溃捕获全部带 `FireKula` 作者和完整版本信息（FileDescription/OriginalFilename/InternalName/ProductName/FileVersion/ProductVersion）。
- **全部自有 EXE 使用自签名调试证书签名**（见下方“签名说明”）。
- **更新链**：v1.0.13-r2 客户端先自动安装 `v1.0.14-bridge`（保留 v1.0.13-r2 入口），桥接后的新登录器再迁移到 `v1.0.14` 的签名入口；需要布局迁移的玩家可用 `DFOLauncher.exe` 一次性整理到 `client\`。

## 签名说明（重要）

本版使用**自签名调试证书**（`CN=FireKula`）签名，不是公共 CA 证书。玩家 Windows 会显示“未知发布者/不受信任”；它**不能**降低 SmartScreen 或杀软告警，也不代表本版已经解决误报。若后续购买受信任 OV/EV 证书，需要重新构建、签名并重新生成清单和入口迁移对。

## 升级与安装

- **现有 v1.0.13-r2**：启动器检查更新 → 下载 `v1.0.14-bridge`（约 216 MiB）→ 桥接完成后新登录器完成入口迁移（约 0.4 MiB）。
- **需要单启动器布局**：把 `DFOLauncher.exe` 放进旧客户端目录运行一次，完成 `client\` 迁移；之后的更新在 `client\` 内进行。
- **全新安装**：解压本版启动包，运行 `DFOLauncher.exe`。

## 已知限制

- `DFLegacy.CrashCapture.exe` 仓库无源码、当前无版本信息，只做了签名，不满足“完整详细信息”。
- 内部 2009 风格 EXE 改名本次未执行，保留现有文件名。
- 调试证书不建立公共信任；签名状态为不受信任（`UnknownError`）。
- 公司电脑实机登录/游戏仍需实机确认。
