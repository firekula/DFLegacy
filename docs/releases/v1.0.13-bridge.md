# 第二章 v1.0.13 过渡更新

第二章 Windows x64 普通版 v1.0.12 玩家可退出游戏后打开原来的登录器。启用自动更新时，旧启动器会先安装过渡组件，然后按原更新源下载 v1.0.13 完整包并核对 SHA-256。

升级将完整包解压到旧目录下的独立客户端目录，复制已保存的账号、登录器选项和游戏设置。新版登录器通过启动校验后，原快捷方式会打开新版。下载中断、解压失败或新版登录器校验失败时，原安装仍可启动。升级期间请保留旧目录及其 `.dflegacy` 文件夹。

本次迁移使用两个镜像已发布的 v1.0.13 完整包。GitCode 路径不依赖 v1.0.13 增量清单。手动安装仍可下载完整包解压到新目录。深渊房侧门的已知问题见 v1.0.13 发行说明。
