# DFLegacy 第二章 v1.0.16

> **2026-11-18 更新：本版本对应的 GitCode Release 已删除。** 当前发行链为 `v1.0.14` → `v1.0.14-bridge`（seq 24）→ `v1.0.15`（seq 25）；本文件只保留当时的构建与验收记录，不代表线上可更新版本。

## 本版内容

- 拆分启动布局收尾：游戏文件留在安装根目录，启动器与 `.dflegacy` 状态进入 `client\`；
  迁移后的首次启动不再被启动预检拦截。
- 启动预检在更新源不可达（含 TLS 中途断开）时降级为离线校验：本地内容完整即进入登录页，
  并明确提示“未确认线上最新版本”。
- 校验收据不再绑定绝对安装路径：整个安装目录改名/搬家后复用已完成的校验记录，不再每次全量重算。
- 线上清单需要替换固定入口时，预检改为“延迟更新”：保留本地安装、本地校验通过后照常启动，
  需要新启动包时由登录器内更新器处理；本地内容损坏仍然硬失败。
- 无法自动识别占用客户端文件的程序时，提示玩家完全退出游戏后重试，绝不猜测关闭进程。
- 版本号 1.0.16。
