# DFLegacy 第二章 v1.0.18

> **2026-11-18 更新：本版本对应的 GitCode Release 已删除。** 当前发行链为 `v1.0.14` → `v1.0.14-bridge`（seq 24）→ `v1.0.15`（seq 25）；本文件只保留当时的构建与验收记录，不代表线上可更新版本。

## 本版内容

- 更新器、修复入口和更新助手现在都用“请求里的安装目录”解析拆分布局（它们可能从 `%TEMP%` 副本运行，
  不能依赖自身所在目录）。
- 游戏目录相关的配置与服务端查找改为安装根：`launcher.chapter2.json`、`Config.ini`、`ijl15.dll`、
  `DFLegacy.Server.exe`；搬家后账号与显示设置不会丢。
- 启动迁移只把启动器与 `.dflegacy` 放进 `client\`，游戏文件留在外层；旧版单启动器布局
  （`client\DNF.exe`）会在下次启动时把游戏文件抬回外层，支持回滚与中断续做。
- 版本号 1.0.18。

## 升级路径

- `v1.0.14` / `v1.0.15` / `v1.0.16` / `v1.0.17` 安装可直接更新到 `v1.0.18`：固定入口与受管理文件集合不变。
