# v0.1.11 客户端与天帷禁地入口修复

本版恢复天帷巨兽选图界面的天帷禁地入口，并将更新窗口阶段提示统一为中文、与标题左对齐及单行省略显示。发布范围为 GitHub 的 x86/x64、普通版/测试版四路客户端更新，配套 V3 兼容更新及固定入口修复包；客户端更新包含新的 `Script.pvf`。

## 发布状态

构建与实机验收进行中。实际公开状态以 GitHub Release 和本地发布回执为准。

## 客户端更新

关闭游戏后双击原来的启动图标，由 GitHub stable 自动更新到 v0.1.11。保持客户端架构和普通/测试类型一致。`launcher.json` 保留本地账号及服务器地址，不作为受管理文件覆盖；配置迁移只合并既有中继端口。更新窗口较长的文件名以省略号显示，悬停可以查看完整文字。

天帷禁地入口要求已接取或完成任务 452「我在大陆的肚子里」，前置任务为 451「疑问的信息」。副本最低等级为 34。已有该任务的角色更新客户端后重新登录即可检查入口，不需要放弃并重接任务。

服务端继续使用现有镜像。进入 18080 部署管理，停止游戏服务，上传并选中以下 PVF，保存配置后重新启动游戏服务：

- 本地文件：`G:/dnf_local/PVF-exports/Script-act1-20261110-behemoth-forbidden-unlock.pvf`
- GitHub Release 附件名称：`Script.pvf`
- SHA256：`b66ee59253013fcae78bed9750d731399e567450104dd8d0c3c83a5ef0f7ab8f`

数据卷、端口及 Compose 环境变量沿用现有配置。客户端和服务端应使用相同 PVF，服务端重新启动后才会重新加载世界地图目录。
