# 第二章资源覆盖校正与指定目录安装

用户要求将最新正式客户端安装到 `G:\Project\DNF2\DNFS1C2`，保留完整资源，清除测试入口，供手动打包。本轮仅修改第二章工作分支和这个明确指定的目录，未操作主线、线上服务或其他日常客户端，也未重新发布客户端。

## 原因和校正

v1.0.1 的资源选择清单包含 ImagePacks2，但遗漏 ImagePacks3/4。之前的附件哈希、更新及回退验收证明了清单内部一致性，不能证明与原始客户端的资源覆盖一致，因此之前“完整包”的资源完整性结论需要更正。

以 `D:\Downloads\Programs\DNFS1C2.zip` 为原始证据：

| 目录 | 文件数 | 字节数 |
| --- | ---: | ---: |
| ImagePacks2 | 551 | 738105558 |
| ImagePacks3 | 0 | 0 |
| ImagePacks4 | 79 | 117036856 |
| Music | 83 | 121078238 |
| SoundPacks | 40 | 194887459 |

指定目录中的上述 753 个资源与原始压缩包逐文件 SHA-256 一致。ImagePacks4 的 79 个文件虽然在 ImagePacks2 有同名文件，但内容全部不同，不可扁平化、按文件名去重或省略。

第二章选择清单已纳入 ImagePacks3/4。正式打包要求 ImagePacks2/4 各自包含资源，并拒绝将缺少源图像资源的旧清单制作成完整包。空的 ImagePacks3 目录在完整压缩包中保留。第一章选择清单未变。

## 指定目录的安装结果

安装前将全部 820 个文件复制到目录外备份并逐文件验证。安装使用与已发布 v1.0.1 相同的正式附件，压缩包 SHA-256 为 `955e15318786e972fafc0aa8b3e791bb098a663a13bbad7cd79014e17cfc889d`。其 705 个受管理文件均校验通过；原始 ImagePacks4 作为补齐资源保留，不篡改已发布版本的更新清单或收据。

六个旧测试 EXE、旧生成运行目录、旧日志和登录配置均移到目录外。保留正式启动入口 `DFLegacy.Launcher.exe`、应用/更新/诊断组件、游戏本体及原始 7z 工具。正式配置不含账号记录，地址为 `games.firekula.site`，调试和测试静音默认关闭。

最终入口以 `--self-test` 执行成功，退出码 0，日志确认原始客户端、嵌入启动组件和固定入口交接通过。本次未进行登录或战斗验收。自检日志及本机校验缓存已移到目录外，避免混入手动分发包。
