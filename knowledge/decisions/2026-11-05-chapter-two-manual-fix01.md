# 第二章手测问题第一轮

| 手测项目 | 修复与复测口径 |
| --- | --- |
| 进图卡顿与部分特效延迟 | 恢复 FPS 和已提交内存。只记录出现慢帧的采样区间，默认关闭逐事件内存转储。进同一张地图时分别使用原始窗口和增强缩放，比较 FPS、最长帧间隔和特效出现时间。 |
| 经验旁的橙色大数字 | 使用角色已保存的胜点余额驱动显示。分别击杀普通怪和进行组队击杀，确认经验正常且没有误报胜点。 |
| 「不使用」及名称不存在的任务 | 从第二章可接列表过滤这些任务，保留正常任务与已有进度。赛丽亚的列表用未勾选和勾选等级筛选各试一次，再接取、放弃一个正常任务。 |
| 商城充值和黑钻 | 服务端管理页开启「允许本机测试点券和黑钻」后重启。游戏按钮、管理页和启动器菜单均走本机测试页面，确认发放和回到商城后的余额刷新。 |
| 仓库格子及整理 | 试移至空格，再用数量不同的两件物品交换背包与仓库占用格，关闭重开核对。整理后检查同种可合并堆叠和超出上限的剩余堆叠。 |
| 摆摊与邮件 | 双开，从 1 格增加至 14 格并由买家核对条目和数量。摊主打开邮箱，领取大于单格上限的附件时检查拆格和负重上限。 |
| 城镇地图及任务图标 | 已定位第二章地图的命中入口和任务图标，寻路和绘制仍待迁移。后续需要分别验收空白点、任务图标覆盖、普通菜单、同区与跨区。 |

测试包仅使用第二章的本机服务和独立存档。商城清单及尚未迁移的第一章原生功能继续分项记录。
