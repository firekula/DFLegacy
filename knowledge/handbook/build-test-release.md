# 第二章修复构建与验收

从统一修复分支构建。记录提交、版本、配置与输出目录，核对最终单文件 App 内嵌的宿主与 broker 摘要，再核对实际会话解出的宿主。发布流程中以 `Build-LauncherRoles.ps1` 钉住的输入摘要为准。同一条模块安装日志在新旧宿主上都可能出现。

App 变动时，通过 V4 事务同步描述文件与安装回执。固定入口的字节受既有清单约束。入口变化随新启动包或经验证的安装迁移交付。

## 验收记录

分开记录构建、自动化执行、用户真机、最终整包与线上发布。构建测试工程只能证明它可以编译。用例记录应包括章别、版本、操作对象、操作前后状态和对应日志。第二章原生和托管角色应核对文件属性、版本与对应的实际启动入口。
