# 接手时常见术语

不熟悉仓库时先查本表，再进入 [手册目录](README.md)。这些说明是本项目中的具体含义。

| 词 | 含义与注意事项 |
| --- | --- |
| ACT1 / 第一章 | 第一章旧客户端产品线；不是“所有章节的通用简称” |
| Chapter Two / C2 / 第二章 | 独立原生启动与资源链，复用部分服务端代码 |
| Server | 游戏业务服务，持有会话并写游戏存档 |
| Manager | 部署控制台与服务进程管理器，登录身份独立于游戏账号 |
| Channel | 可指频道概念，也可指可选独立入口进程；要看上下文 |
| Launcher | 桌面登录器；发行文件名也用于原生固定入口，需核对实际角色 |
| Startup / 固定入口 | 安装后供用户启动的原生 EXE，先做校验/恢复并启动托管登录器 |
| bootstrap | 受控启动交接协议；游戏引导器与固定入口并非同一程序 |
| broker | 第二章原生启动代理，与显示宿主协作启动游戏 |
| PresentationHost | 第二章 x86 兼容显示宿主；构建需要锁定的外部输入 |
| native / 原生 | 本项目通常指 C/C++ Windows 模块，而不是 .NET 托管代码 |
| managed / 托管 | 运行在 .NET 上的 C# 程序或库 |
| RID | .NET 运行时目标，如 `win-x64`、`linux-arm64`；不等于游戏本身位数 |
| PVF | 游戏脚本资源包；第二章客户端/服务端封装可不同 |
| NPK / IMG | 客户端图像容器/图像条目，关系到显示与布局 |
| Catalog | 服务端从资源构建的查询目录，如物品、技能、地下城规则 |
| CMD / NOTI / opcode | 命令/通知/协议号；必须同时说明方向、协议族与章别 |
| Relay | 中继；可能是客户端 IPv4/IPv6 转发，也可能是玩法组队回退服务 |
| DataPath / state.json | 游戏持久化快照文件，不能让两进程并发写同一个文件 |
| transaction / 事务 | 一组修改作为整体提交或恢复；商店/交易/更新各有自己的事务 |
| idempotency / 幂等 | 同一操作重试不会重复扣费、发物品或完成结算 |
| lease / 租约 | 限制某项资源或控制权当前由谁使用；不同模块实现不同 |
| V2 / V3 / V4 | 客户端包/更新协议世代，不是 .NET 或游戏章节号 |
| sequence | 更新清单单调序号；不能把发行版本文本当作同一个字段 |
| manifest / receipt | 文件/版本清单及处理回执；存在不等于所有内容已经校验 |
| SHA256 / digest | 文件或镜像内容身份；不是数字签名，也不证明业务正确 |
| PDB / CodeView | Windows 调试符号及匹配身份；同名 PDB 未必对应当前 EXE/DLL |
| fixture / 夹具 | 可控测试输入或状态；不代表玩家自然操作 |
| actor | 一次验收中的参与客户端，如 A/B/C/D，需绑定实际进程身份 |
| run | 一次测试执行及其证据集合，不是一个永久在线服务器 |
| smoke | 冒烟测试；本项目很多是 `dotnet run` 启动的自定义执行器 |
| U07 / U08 / GP42 | 历史任务或问题编号，具体含义与边界须看对应日期报告 |
| 假人 / 虚拟玩家 | 有稳定身份、可参与城镇/社交/战斗的虚拟玩家；当前没有正式实现，只有调试幽灵 |
| 调试幽灵 / TownGhost | `TownGhostService` 合成的城镇成员；只显示/走动/消失，不接收报文、不持久化、不结算 |
| 地区频道 | 按 PVF 区域划分的可选入口；当前只实现列表与通关经验，城镇/组队隔离未完成 |
| 章别适配 | 把功能从一个章节迁到另一个章节时，对协议、资源、原生地址、构建和发布的分别核对 |

遇到未列名词时，先搜索定义及调用，不凭名字创造接口或配置字段。
