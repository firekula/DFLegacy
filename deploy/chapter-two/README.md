# DFLegacy 第二章 Windows 管理器

1. 将 ZIP 完整解压到一个新的可写目录，双击 `Start.cmd`。浏览器会打开本机管理界面 `http://127.0.0.2:48092/`。
2. 第一次运行时创建部署管理账号，密码至少 12 个字符。管理账号只用于管理进程。需要时可在服务配置中创建独立的游戏管理员，普通游戏账号可以在配套登录器注册。
3. 在「运行概览」点击「启动服务」，看到「运行中」后再使用第二章客户端登录。以后双击 `Start.cmd` 默认会自动启动游戏服务。
4. 在「运行概览」可以停止或重启游戏服务，在「运行日志」查看服务端和管理器日志。关闭浏览器不会停服。结束测试时先在管理页停服，然后在启动窗口按 Ctrl+C 退出管理器。
5. 需要测试商城、摆摊或仓库时，在「服务配置」勾选「允许本机测试点券和黑钻」，保存并重启服务。然后从「运行概览」打开测试页面，输入已有角色名和数量。此项默认关闭。

包内附有 Windows x64 运行时和第二章适配 PVF。客户端和账号接口使用同一台电脑上的回环地址。默认游戏存档在 `data/game/state.json`，滚动日志在 `data/logs/manager.log`。管理器端口为 48092，游戏账号接口为 `http://127.0.0.2:48091/`。更换已有测试存档前请先停服并备份。

测试商城前，在「服务配置」开启「本机测试充值」，保存后重启服务。可用管理页、启动器菜单或游戏商城的充值按钮打开本机页面。点券和黑钻发放到本机测试存档。
