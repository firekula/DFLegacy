安装说明

先退出游戏并备份客户端，按 Windows 系统位数选择内层 x86 或 x64 ZIP，将内容解压到 DNF.exe 所在目录，再运行 DFLegacy.Launcher.exe。新版使用独立 DFLegacy.Client.dll；旧用户需在登录器中确认一次经哈希验证的原版 IJL 恢复。仅支持同版本兼容展开客户端，保留原始 EXE、DLL、PVF、NPK。缺失配置自动生成，已有 Config.ini 仅更新必要连接设置。

发行包不含游戏客户端或 Script.pvf。普通版不加载诊断；测试版默认在首个游戏内画面加载本地诊断，主动测试控制仍需显式开启。仅服务端覆盖数据需要共享本机目录。内嵌 Detours 完整许可和版本信息，可运行 DFLegacy.Launcher.exe --third-party-notices | more 查看。游戏内充值页面继续使用 460×315 布局。
